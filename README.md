# FizzBuzz

An interactive browser exercise that reveals the FizzBuzz sequence one item at a time.

**[Try the demo](https://usmanbutt-dev.github.io/fizzBuzz/)**

## How it works

Click the button or press Enter or Space to add the next number. Multiples of 3 become `Fizz`, multiples of 5 become `Buzz`, and multiples of both become `FizzBuzz`. JavaScript appends each result to the list and scrolls it into view.

## Run locally

Open `index.html` in a browser. The page uses `style.css` and `index.js`, with no dependencies or build step.
